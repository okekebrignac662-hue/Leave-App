🔄 ซิงค์ข้อมูลทั้งหมด (Sync All)

ส่งทั้งคำขอลางานทั้งหมด และรายชื่อพนักงานทั้งหมดแยก 2 แผ่นงาน

ส่งประวัติการขอลางานทั้งหมด และจัดสีสถานะ (อนุมัติ/รอ/ปฏิเสธ)

ส่งรายชื่อพนักงาน แผนก กะการทำงาน และโควตาวันลาเริ่มต้น

1
สร้าง Sheet ใหม่

2
เปิด Apps Script

3
วางโค้ดสคริปต์

4
Deploy เว็บแอป

กด Deploy > New deployment เลือกประเภท Web app และสิทธิ์ ทุกคน (Anyone)

5
นำ URL มาใส่
